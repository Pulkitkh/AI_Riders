Why it can be trusted

  • It only listens. The part that detects threats cannot open a network connection — proven, not promised (see Read-only proof).
  • No decryption. It reads only the shape and timing of traffic, never the private contents.
  • Every alert explains itself. Click any alert to see, in plain words, what it means and what to do.
  • Tamper-evident record. Alerts are chained so a past record cannot be quietly edited.
  • Runs anywhere. Pure Python, zero dependencies — installs even on an offline machine.

Honest caveats

    Every alert is appended to a SHA-256 hash-chained log. It is not a blockchain — it is tamper-evident: change one byte of one past alert and re-walking the chain names the record that broke. This is what the CERT-In 180-day retention duty actually needs.

    Constraint (a): the sensor sits behind a diode — traffic in, nothing back. Before any detection, here is the property everything depends on. This walks the syntax tree of every module in the detection path and fails if one imports a socket, an HTTP client, or scapy. It also counts the sockets this interpreter holds.
